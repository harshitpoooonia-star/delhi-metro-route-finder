# Quickstart

## Build and test

```sh
make
make test
```

`make test` should print `all tests passed`.

## Check by hand

1. `./metro`, pick 1, enter `knowledge park ii` then `rajiv`. The route changes from Aqua to Blue at Sector 51 / Sector 52.
2. Pick 2, enter `sec`. Every Sector station is listed.
3. Pick 3, enter `Magenta`. Stations print end to end.
4. Pick 1, use the same station twice. You get `start and end are the same`.
5. Pick 4 and add a station, pick 5 and link it, exit, restart, route to it.
